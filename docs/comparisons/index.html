Sample provenance & operating points

These four examples use each method’s own lowest-rate operating point. They are not matched-bitrate comparisons. RIFT is QP63; GLC is QP0. A star marks GLC’s official entropy-estimated bpp; RIFT uses actual rANS payload bpp.

The full-resolution WebP files are lossless. Full-frame and detail views use the same crop coordinates across all methods. Frame indices are zero-based.
